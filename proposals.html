提案 / 创作

Propose & Create

本站是指引和目录，不在此做原生表单。提案走共创流水线；投票全部引导外联盟平台（Discord + Reddit + Bluesky），本站不承接投票交互。

This site is a guide and directory — no native forms here. Proposals go through the co-creation pipeline; all voting routes to external platforms (Discord + Reddit + Bluesky) — no voting UI on this site.

Co-creation Pipeline
