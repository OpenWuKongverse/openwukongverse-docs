# OpenWuKongVerse · 参与须知 / FAQ\n## 首批创作者常见问题速答\n\n> 状态：待发布 · 配套主文案 `marketing/main_recruit.md`\n\n---\n\n## Q1：这到底是个什么项目？动画？小说？游戏？\n\n都不是单一体——它是一个**可扩展的世界观宇宙 + 社区共创协议**。在这个底座上，动画、漫画、小说、游戏都是可衍生的“模态表达”。第一批共创先把宇宙“长出来”，再谈形态。\n\n## Q2：我不懂硬核科幻/物理，能参与吗？\n\n能。三层红线里“法则自洽”指的是**不与既定法则冲突**，不是要你懂物理。卷4《底层协议手册》给了可直接套用的“法术书写范式”（[法术名]=[接口调用](锚点,权限,代价)），照范式写就行。世界观爱好者只投票也能参与（观测者位）。\n\n## Q3：我的创作会不会被随便改掉？\n\n不会。署名权归你；进入正典的内容被采纳后保留你的贡献记录与维度积分。主线历史不可改写，但你的支线、洞府、局部设定受“局部沙盒自由定律”保护。\n\n## Q4：我能赚到钱吗？\n\n商业化后：衍生收益的 **30% 流入共创者收益池**，按维度积分分配。维度积分从 C1（创作量）/C2（质量）/C3（采用率）/C4（生态贡献）四个维度累计，现在攒积分，变现启动后按积分分润。\n\n## Q5：版权怎么算？\n\n正典基础内容采用 **CC BY-NC-SA 4.0**（署名-非商业-相同方式共享）。你的个人署名权保留；进入正典后按公共许可共享，同时保留分润权。商业使用走项目生态协议。\n\n## Q6：要交钱吗？\n\n不。首批招募零门槛。\n\n## Q7：会不会被某个人/小圈子垄断？\n\n设计上防了三层：① 管理员权限受限（不能直接改高维规则，见卷1/卷3）；② 匿名性保护（发起人与参与方身份隔离）；③ 治理是“架构师评审团 + 社区代表”共识制。质量分由社区加权，非单一点赞。\n\n## Q8：现在还能报名吗？怎么报？\n\n仓库当前为私有，正式报名入口随**仓库公开 / 项目启动**开放（届时见 `marketing/main_recruit.md` 补充）。想提前参与的，可先读卷4 上手，准备好你的第一个提案。\n\n## Q9：从哪里开始读？\n\n- 想看宇宙全貌 → README（入口）\n- 想感受世界观氛围 → 卷2《世界观圣经》\n- 想立刻开写 → 卷4《内容目录》+ 卷3《共创协议》\n- 想看“我能拿到什么” → 共创协议草案 + 卷3\n\n## Q10：为什么叫“开源悟空多维宇宙”？\n\n“开源”指世界观的共创共享协议（CC BY-NC-SA + 社区共建）；“悟空”是取经纠错进程的象征（杀毒程序）；“多维”是宇宙的物理形态（五层膜）。合起来即：**一个由社区共同维护、以科学为底的多维宇宙。**\n\n---\n\n## 快速参与三步\n\n1. **选入口**：画师→洞府视觉 / 编剧→八十一难 / 玩家→模态+维度地图（卷4）\n2. **自检三层红线**：法则自洽？权限自洽？元层自洽？\n3. **提交第一个提案**：走流水线（提案→评议→审查→入正典/沙盒）\n\n---\n\n> 项目发起人：Echo-Architect-0\n> 文档开源许可：CC BY-NC-SA 4.0\n> *OpenWuKongVerse · 让《西游记》以科学的姿态重生*\n
