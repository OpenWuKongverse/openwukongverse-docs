世界观速览

下面是整套宇宙设定的精华速览，完整内容见正典库（卷1《概念协议》· 卷2《世界观圣经》）。

一句话

宇宙默认熵增，靠周期性的 序态自稳系统（原「负熵稳定系统」）纠错维持低熵；\n 取经就是一次纠错心跳，八十一难就是系统的一次次单元测试。

五层膜宇宙（真实物理结构，本尊）

层维度定位神话对应
灵山5D全息奇点（系统最深处的收敛点）「灵山胜境」
天庭4.5D观测站（层级管理者视角）「天宫」
凡间3D基底物理层（主舞台）「人间」
地府4D负熵回溯场（信息回收/平衡）「阴司地府」
局部真空泡—五层膜之外的封闭小空间（妖怪洞府）「洞天福地」

五重物理法则

法则含义
界维度
境边界 / 真空泡
道代码 / 阴阳五行
法权限调用
心终极观测者

权限受限原理

Root / Admin 不能直接修改高维规则，只能借低维进程触发；紧箍咒 = 维度锁。\n 这是「强者不能平白无敌」的物理根基——再强的能力也必须落在合法权限或受限授权内。

观象域（投影幕布层）

人类所见《西游记》的神话镜像（腾云驾雾、七十二变等）发生在观象域（Observational Mantle），\n 是宇宙本尊经神话滤镜降维投影的影像，不是宇宙本身。

术语红线：五层膜 = 真实结构本尊；观象域 = 神话投影镜像。二者不混写。

三模态（同一宇宙，三种呈现）

模态 A

赛博

法术 = 代码调用；法宝 = 设备；天庭 = 云端主权

模态 B

高维玄幻

修真法则；法术 = 高维物理的古典外观

模态 C

废土 · 克苏鲁

世界维度崩坏后的衰败投影；露出高维不可名状真实

三模态都是对同一本尊的不同呈现滤镜，换滤镜不换物理本尊。创作时选定主攻模态。

想深入？正典库完整设定见 GitHub 仓库卷1《概念协议》与卷2《世界观圣经》，介入点见《介入点索引》（A/B/C 三类缝）。
