积分看板

本站只读展示积分 结构与规则。实际记账在 Hub 事实源（GitHub 仓库），随入库/评审即时更新（公示 D3：事实源永远实时）。

维度积分（贡献力计算）

维度内容权重
C1 · 创作量入正典内容量 / 有效提案数30%
C2 · 质量分社区评议加权（评审团 + 观察者投票）30%
C3 · 采用率提案被采纳 / 入正典的比例20%
C4 · 生态贡献评审、架构、翻译、社群维护等非创作贡献20%

各维度归一化后加权求和 → 维度积分。入正典内容标记贡献者身份与当次积分，累入其账户。防刷：质量分由社区加权而非单一点赞，异常聚类触发复核。

多池分润结构（决策已定）

池基线比例当前状态说明
创作池40%40%按维度积分 C1–C4 + 资产深度系数分配
生态运维池20%20%生态岗回报（翻译/社群/评审/治理/工具）
IP 资产池20%暂不启用（独立挂起）资产化启动时直接启用，份额保留
生态回流基金20%20%回投衍生内容/活动/工具/孵化；管理方=架构师评审团+社区代表
合计100%100%任何分配恒守恒

积分怎么用

  • 分润分配基数（第六章多池分润）
  • 共创角色晋升：观察者 → 正式共创者 → 评审团
  • 模态坍缩投票加权：影响 W(A/B/C) 权重周期重算
模态坍缩底线：三模态权重最低不低于 15%（多样性底线），单一模态不会被完全边缘化；你的创作持续计入，可触发该模态的坍缩收敛。
