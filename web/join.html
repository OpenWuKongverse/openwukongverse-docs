报名加入

本站不做原生表单，报名走 邮件 + 微信 双入口（决策 D2 已定），提交后进入观察者身份，可逐步晋升共创者。

双入口（决策 D2）

入口 1 · 邮件

邮件报名

发送报名邮件（意向角色 / 模态偏好 / 自我介绍）。邮件方式适合国际用户与偏好正式沟通者。

报名邮箱待站内正式公布（此处为示意占位）。

入口 2 · 微信

微信表单

国内相关方可通过微信表单登记（域名、语雀/腾讯文档工具栈）。适合国内创作者与画师社群。

微信表单链接随报名启动公布。

备选 · Discord

Discord 人工报名

国际社区可在 Discord 内由管理人工登记报名，作为双入口之外的人工备选路径。

报名后是什么身份

身份说明权利
观察者 / 读者开放注册的受众（门槛最低）阅读、投票、点赞、影响模态坍缩权重
正式共创者通过注册与准入的个人/组织提交提案、创作内容、参与评议投票、享分润权
评审团社区推选/共识产生审查提案正典兼容性、仲裁贡献与分润争议

共创能做什么

  • 按介入缝创作：从《介入点索引》挑 A/B/C 三类缝（支线缝合 / 模态坍缩 / 前史后传）。
  • 提交提案：用《共创提案模板》一页提交，走流程 提案 → 评议 → 架构师审查 → 入正典/沙盒。
  • 参与评议：在各平台（Discord / Reddit / 微信）对候选提案投票、讨论。
  • 换模态主攻：A 赛博 / B 高维玄幻 / C 废土克苏鲁，任选并参与坍缩权重。
铁律：主干不可改（主线历史不可更改），只能丰富支线/补完局部；改系统级设定须先提案级讨论后再入正典。
