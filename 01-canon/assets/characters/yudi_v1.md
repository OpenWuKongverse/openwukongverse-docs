## 正典定位

玉帝 = **Sys-Macro-Admin（天庭子系统管理员）**，Level 4。管辖天庭子系统、维护秩序常数、（按 Admin 职能）注入天条。他是天庭这座 4.5D 观测站的子系统管理员，权限级别为 Admin（高级）。

## 定义与机制

- **权限级别**：Admin（卷3 权限矩阵，08-29 核验归位补录），高级。
- **职权**：管辖天庭子系统、发放权限凭证、维护秩序常数/注入天条（卷2 Level 4）。
- **权限受限（修订1）**：同如来受限——不能绕过事件篡改结局，不能直接改写高维底层规则，只能借低维进程触发。
- **关键定位**（卷2 注记）：管理员可调度、可授权、可观测，但不能绕过事件本身去篡改结局。玉帝虽为天庭子系统最高执行者，仍受同一权限受限原理约束。
- **与悟空冲突（大闹天宫）**：悟空破维度形态冲击天庭子系统 → 暴露 Admin 权限无法直接处置异常资源（该异常仅 Root 级奇点手段可隔离，见 N8 五行山）。

## 关联介入缝（必填）

- **A/B**（天庭子系统运作）：玉帝作为 Admin 的日常调度、天条注入机制（4.5D 观测站内部治理）
- **C**（大闹天宫后效）：ADmin 被破维度形态冲击后，天庭内部的系统补丁/反思过程
- **—**（红线）：玉帝不能篡改结局、不能直接改写底层规则；任何"玉帝直接动手镇压悟空"（绕过低维进程/奇点）即越界
