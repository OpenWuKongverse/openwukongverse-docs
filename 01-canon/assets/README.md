# 设定资产库（OVWK-ASSETS）

> 层级：内容层（Content Layer）· 卷4 的应用层资产库
> 性质：把世界观"原则"翻译成**可检索、可共创、可增量**的具体设定条目，供创作者按需取用。
> 编者：Echo-Architect-0
> 日期：2026-08-29

## 本库定位

卷2 定"物理法则"，卷4 定"创作框架"，但**具体的角色、法术、法宝等条目**需要一个可持续扩充的资产库。本目录即为此而生：

- **每条设定独立成文件** → 可独立提案、独立评审、独立索引（QMD `projects-owkv` 集合覆盖）
- **可增量** → 创作者按卷3 流水线提案，评审通过后入库
- **正典兼容** → 每条须过三层红线（法则/权限/元层自洽，见 00-core/volume4 与 volume2）

## 目录结构

```
assets/
├── characters/   # 人物档案库（核心角色+配角，可创空间）
├── magic/        # 法术设定库（法术=维度操作，呼应卷4 1.3 书写范式）
├── artifacts/    # 法宝设定库（法宝=受限维度权限的具象化）
└── tunnels/      # 维度隧道/真空泡通道（⏸ 待议——定义未定，暂留空）
```

## 入库规范（资产库管理约定）

1. 每条设定 = 一个 md 文件，命名 `slug_vN.md`（N=递增版本）
2. 头部含：文档代号 / 归属块 / 版本 / 编者（统一 Echo-Architect-0）/ 关联卷章
3. 内容先对照 00-core/（卷2法则 + 卷4范式）自洽；改系统级设定 = 先提案级讨论，定稿前不入本库
4. 钩子节点（菩提 N6 / 真假 N18 / 后传 N20）留白不挑明
5. 库内文件随 `qmd update` 入索引，语义检索可命中

## 待议

- **tunnels/**：维度隧道&真空泡通道的定义归属待拍板（物理层 or 内容层），暂空
