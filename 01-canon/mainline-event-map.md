## 0. 本卷定位与用途

这张地图供三类人使用：
- **编剧** → 挑一难/一支线节点写剧情；
- **画师** → 挑一节点做视觉（洞府/角色/场景）；
- 玩家/世界观爱好者 → 借节点理解主线如何在三种模态下呈现。

三条铁律（创作基线）：
1. 主干不可改（Canon Events）：节点事件与"系统定位"是硬骨头，任何共创不得推翻/改写其系统语义（卷2 主线历史不可更改）。
2. **介入缝可自由**：每个节点标注的 A/B/C 介入缝，是共创者的合法自由区：丰富支线、补完未记录冲突、写失败坍缩、写模态另面（卷2 + 卷3 沙盒定律）。
3. 观象域 vs 五层膜 术语红线：描述"人类所见神话呈现"用观象域；描述"真实世界结构"用五层膜，禁止混写（卷1↔卷2 衔接声明）。

> **三条铁律 · 领域说明**：以上三条为**内容创作的硬边界**（管"能写什么"）。对比卷3 的"三大沙盒定律"（正典兼容/局部沙盒自由/版权分润）属于**提案治理机制**（管"怎么通过"）。assets/README 另有"入库规范"（资产库管理约定），管格式与流程。**三者领域不同，不互相替代。**

**附 · Level 双义红线**：本地图中标注的维度（灵山/天庭/凡间/地府/真空泡）= **维度层级**（拓扑）；凡角色相关标注 = **权限级别**（卷3 矩阵）。二者数字代号可相同但概念不同，禁止混用。

## 1. 三幕主干（Canon Skeleton · 系统级，不可改）

> 这是主线的"物理骨架"：不是剧情，而是序态自稳系统的运维动作链。任何具体节点都挂在这条链上。

```
【第一幕 · 熵增预警】系统默认滑向信息混乱（乱世底色）
        │                         ↑
        ▼                         │ 低熵恢复，系统进入相对稳定
【第二幕 · 纠错授权】序态自稳触发 → Root受限授权 → 组队取经（低维进程链路）
        │
        ▼
【第三幕 · 纠错执行】八十一难 = 单元测试序列 → 完成官方收敛线 → 心跳成功
```

- 一句话闭环： 宇宙会自然衰退（熵增=乱世），取经是给它打"维持有序"的补丁（负熵=序态自稳）。取经在物理上**必要**，不只是道德使命（卷2 增补）。
- 主干非唯一路径： 取经成功是"官方收敛线"，但不是唯一可能路径：三模态（A/B/C）即多条坍缩路径的共存（卷1 三模态分支）。

## 3. 介入缝说明与共创建议

> 对齐卷3 共创流水线：任何介入先走"提案→评议→架构师审查→入正典/沙盒"双轨道。标注的介入缝是**合法自由区**，但写的作品仍须过三层红线（法则/权限/元层自洽）。

### A 类 · 支线缝合缝（入门级，安全区，推荐新手）
- **定义**：主干节点之间、内部未被官方叙事记录的具体冲突/行程/角色往事。
- **权限边界**：不碰节点系统定位，只丰富细节与因果。
- **高价值区**：花果山生态、五行山五百年、沙僧/八戒/白龙马受罚前史、各洞府奇异物理、老鼋之约、被逐期间的悟空（节点16 后空白）。
- **最容易上手**（卷4 妖怪洞府=创作乐园，从洞府入手最稳）。

### B 类 · 模态坍缩缝（进阶区，价值最高）
- **定义**：同一 Canon Event 在三模态（A赛博 / B高维玄幻 / C废土克苏鲁）下的不同呈现。
- **权限边界**：三模态均服从观象域元层规则 + 五层膜物理法则；模态坍缩权重 W(A/B/C) 动态调权（卷3 第六板块，多样性底线15%）。
- **高价值区**：出世（节点4）、大闹天宫（节点7）、三打白骨精（节点16）、真假美猴王（节点18）、收敛线（节点20）：这些节点天然适合做"三模态对照表"。
- **直接喂模态机制**：写某一模态的标准剧情，即参与坍缩权重。

### C 类 · 因果前史/后传缝（专家区，想象力天花板最高）
- **定义**：主干之外的时间纵深：前史（系统建立前/菩提/五行山/真空泡来源）与后传（取经后的循环）。
- **权限边界**：改动系统级设定须过架构师审查；建议先做"提案级"讨论而非直接入正典。
- **高价值区**：悟空异常体的来源（S0 起源钩子=最早的缝，来源不定死，可分裂支线）、菩提越权授艺的因果（节点6，卷4 已点名"隐秘Root勿过度解释"：建议保持神秘，只挖边界不挑明）、真假美猴王的本体（节点18，可分裂支线）、熵增阈值设定（节点3）、取经后的新循环（节点20）。
