## 0. 定位与红线（起步版，先跑起来）

- **不存原图，只存 WebP 展示版**。创作者自己保留源文件（本地/自有网盘），OWKV 侧**只有在线可看的压缩展示版**——网络浏览清晰即可。
- **不碰商业化**。原图存档、源文件、周边授权一律不在本项目范围（待真需要时再说）。
- **存储三件套分工**：GitHub（轻·文本+缩略）/ B2（重·展示 WebP）/ CF（CDN 加速分发）；数据回流走既有 `contribution-data-spec`。
- **公开只出压缩版**，不直链原图（防带宽滥用 + 护创作者著作权）。

---

## 1. 为什么这样分层（三件套各扛什么）

| 载体 | 放什么 | 理由 | 成本 |
|---|---|---|---|
| **GitHub 仓库** | 故事文本、脚本、提案 MD、**缩略 WebP**、正典、积分快照 | 免费、版本化、留痕；GitHub **不宜放大图**（单文件 100MB 墙 + 仓库 ≤1GB 建议） | 免费额度足够（纯文本+缩略） |
| **Backblaze B2** | **展示用 WebP**（放大档/大图档） | 便宜量大：免费 **10GB**，超出 $0.007/GB/月；S3 兼容，可公开直链当图床 | 免费 10GB 起步，WebP 展示版很难填满 |
| **Cloudflare（CF）** | **CDN 加速 + 图床分发**；CF D1 记数据事件（既有） | 全球 CDN 免费档、加速 B2 直链；D1 已在上承载数据契约 | 免费档够用 |

**原则一句话**：**GitHub 存"轻"（文本+缩略），B2 存"重"（展示 WebP），CF 做分发与记账。** 各自免费额度内跑得起。

---

## 2. 美术 WebP 分档（只存展示版）

| 档位 | 用途 | 建议规格 | 体积量级 | 存哪 |
|---|---|---|---|---|
| **缩略 WebP** | 站点列表/卡片渲染 | 长边 400–800px | 30–100 KB/张 | **GitHub** `previews/` |
| **展示 WebP** | 站内/Reddit 预览 | 长边 1600–2000px, q≈80 | 150–400 KB/张 | **B2** 公开直链 |
| **放大 WebP** | 点开细看 | 长边 ≤2400px, q≈85 | 0.5–1.5 MB/张 | **B2** |

B2 免费 10GB 按 200–500KB/张估算 ≈ **2万–5万张**，纯 WebP 展示层几乎填不满，免费档长期够用。

## 3. 内容提交与展示链路（补上的缺环）

```
共创者提交美术
   └─ 上传 → 自动转 WebP（缩略档 + 展示档）→ B2 公开直链（+ 缩略档进 GitHub previews/）
   └─ 原图/源文件：不传（创作者本地保留）
共创者提交文本（故事/脚本/提案）
   └─ GitHub 仓库 PR/Issue（版本化留痕，主通道）
观察者
   ├─ Hub 站作品集 = GitHub 缩略渲染（快）+ B2 WebP 放大（清晰）
   ├─ Reddit 帖 = 挂 WebP + B2 链接 → 投票评议
   └─ Discord = 讨论 / 评审
评审/入库
   ├─ 入正典作品 → 正典条目存 WebP + 元数据（指 B2/仓库预览，不存原图）
   └─ 其余投稿 → 停留投稿层（B2 WebP），不升格
数据回流
   B2/GitHub 上的作品元数据 / 评审 / 投票 → CF D1 记事件 → 积分 → 公示
   （沿用 contribution-data-spec：events_raw → ledger → 快照 → 门面站只读渲染）
```

---

## 4. 红线

- **公开一律只出 WebP 压缩版**，B2 不存也不直链原图/源文件。
- **GitHub 只进"轻"内容**（文本+缩略 WebP），美术大图原格式一律不进仓库。
- **原图归属创作者**：OWKV 侧无源文件存档义务；未来如确需衍生（周边/画册）再按作品单独向创作者索取，非本稿范围。
- **数据仍回流单一事实源**（Hub/CF D1），平台只做展示/传播，不重复记账、不因平台割裂积分。

---

## 5. 落地边界

- **本稿为内容存储与展示规格**，与 `contribution-data-spec.md`（数据契约）分工明确，互不覆盖。
- **落地实现**（B2 建桶 / 上传转 WebP 脚本 / CF 分发接入）属实现阶段，待本项目跑起来后逐项兑现；起步可先手工上传 + 站内展示，无需一上来全自动。
- **商业化/原图存档/著作权留档**：明确**不在本稿**，待项目验证后再议。
