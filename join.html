共创能做什么

What Co-creation Can Do

  • 按介入缝创作：从《介入点索引》挑 A/B/C 三类缝（支线缝合 / 模态坍缩 / 前史后传）。
  • 提交提案：用《共创提案模板》一页提交，走流程 提案 → 评议 → 架构师审查 → 入正典/沙盒。
  • 参与评议：在各平台（Discord / Reddit / 微信）对候选提案投票、讨论。
  • 换模态主攻：A 赛博 / B 高维玄幻 / C 废土克苏鲁，任选并参与坍缩权重。
  • Create at intervention slots: pick an A/B/C slot from the Intervention Index (branch-sewing / mode-collapse / prequel-sequel).
  • Submit proposals: one page via the Co-creation Proposal Template, following Propose → Deliberate → Architect Review → Canon/Sandbox.
  • Deliberate: vote & discuss candidate proposals across platforms (Discord / Reddit / WeChat).
  • Switch home mode: A Cyber / B High-Dimension Xuanhuan / C Wasteland-Khthonic — pick and join the collapse weighting.

多语言认领（翻译 = C4 生态贡献）

Language Claiming (translation = C4 ecosystem contribution)

HUB 站官方双语为 中文 + 英文（人工把控术语口径）。更多语言以共创认领方式开放——认领即承担该语言的正典/站点翻译，按 C4 生态贡献记维度积分；翻译须对照术语对照表（正典三语口径），不得引入机器翻的伪术语。

The HUB site officially ships manual Chinese + English (terminology controlled). More languages open via co-creation claiming — claiming means taking on that language's canon/site translation, scored under C4 ecosystem contribution; translation must follow the terminology alignment table (canonical trilingual wording) and must not introduce machine-garbled pseudo-terms.
