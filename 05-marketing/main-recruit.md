## 我是谁 / 这是什么

我们正在构建 OpenWuKongVerse（开源悟空多维宇宙）：一个把古典名著《西游记》重写为多维物理 + 量子力学 + 信息计算论硬科幻宇宙的 Web3 社区共创 IP。

在这里：
- **腾云驾雾** 是能量跃迁，**七十二变** 是多相叠加态，**紧箍咒** 是权限锁，**金箍棒** 是时空锚点，**取经** 是系统的一次纠错心跳。
- 宇宙分层而存：五层膜（真实结构）+ 观象域（我们所见的神话镜像）。
- 三条平行支线（A 赛博 / B 高维玄幻 / C 废土克苏鲁），你可以挑一条接入。

> 全案体系见文档集（卷1 概念协议 / 卷2 世界观圣经 / 卷3 共创协议 / 卷4 内容目录），已在私有仓库建档，公开后随本案一并放出。

## 为什么加入

1. 你是在共创宇宙，不是在写同人。
共创者的每个设定都是高维系统的观测输入（“桥四”），会真实影响宇宙演化方向与模态坍缩权重：你的创作就是宇宙的一部分。

2. 强设定 + 高自由度，不互相打架。
三层红线保正典兼容，但妖怪洞府（局部真空泡）允许你对局部物理常数拥有绝对裁量权（比如设计一个必须靠声波维持形态的“音波洞府”）。自由有边界，但边界清晰且辽阔。

3. 贡献可度量，利益可分润。
- 维度积分（C1 创作量 30% + C2 质量 30% + C3 采用率 20% + C4 生态 20%）度量你的贡献。
- 商业化衍生收益进入总池，按多池分润分配（创作池 40% / 运维 20% / 资产池 20% 挂起 / 回流 20%），按积分分给你。
- 正典基础采用 CC BY-NC-SA 4.0，个人署名权留给你。

4. 匿名性保护。
发起人与参与方身份隔离，防止中心化胁迫：**创作独立性第一**。

## 怎么加入

**第一步：读入门。**
- 想感受宇宙氛围 → 先读卷2《世界观圣经》
- 想直接上手创作 → 先读卷4《内容目录》+ 卷3《共创协议》
- 想了解全貌 → README 四卷导航顺序读

**第二步：选一条线入口（卷4 三条路线）。**
- 画师 → 洞府视觉
- 编剧 → 八十一难
- 玩家 → 模态 + 维度地图

**第三步：挑一个介入缝，填一份提案（直接可用工具）。**

我们已经把"从哪下笔"到"怎么提交"整理成一套可直接用的工具：
1. **挑缝** → 看 `01-canon/mainline-event-map.md`（主线坐标底图，A/B/C 三类介入缝已内嵌标注）；想按类找活干 → `01-canon/intervention-index.md`（27 个介入缝分类汇总 + 检索速查）。
2. **填提案** → 用 `02-co-creation/proposal-template.md`（一页可填，附 A/B/C 三类示范，新手照着抄就能提交）。
3. **提交** → 按流水线走：提案 → 评议 → 架构师审查 → 入正典（或进沙盒）。三秒自查三层红线：法则自洽？权限自洽？元层自洽？

> 新手小贴士：从沙盒轨道 + A 类介入缝起步最稳：局部自由、不碰正典、易过审易出亮点；洞府（局部真空泡）类提案最容易出彩。

**第四步：攒维度积分，参与分润与治理。**
创意从观象域出发，收益回到你手里。
